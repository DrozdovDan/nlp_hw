# Тематическое моделирование

Вот что требуется для получения полного балла.

1. Реализовать инвертированный индекс для эффективного подсчёта $D(w1, w2)$ -- в скольких документах встречаются два данных терма.
2. Реализовать построение разреженной матрицы для эффективного подсчёта числа соупоминаний двух термов в пределах заданного окна.

Всё это делается в файлах `simple_*`. А сам подсчёт -- в скрипте `a00_general_domain_data_counts.py`.

3. Реализовать C_UMass и C_NPMI в `a01_homework_coherences.py` (если грозит деление на ноль, в UMass возвращаем минус-бесконечность, в NPMI -- `-1`). Убедиться, что они проходят тесты в `a01a_test_coherences.py` (хотя бы примэрно).
4. Подобрать с помощью Optuna лучший по перплексии и разнообразию (perplexity & diversity, три Парето-оптимальных значения) вариант LDA: в качестве гиперпараметров для перебора использовать число тематик, итераций, обрезание корпуса, а также альфа и тета, см. `a02_optimizing_perplexity.py`. Подсчитать значения c_NPMI и c_UMass с помощью реализованных вами функций.
5. Визуализировать результаты с помощью pyLDAVis.
6. Подобрать с помощью Optuna лучший по перплексии вариант Labeled LDA, используя метки в выданном наборе данных. См. a03_optimizing_perplexity_for_llda.py.
7. Используя наработки по пунктам 1, 2, 3 и частоты, подсчитанные на вики-датасете, оценить интерпретируемость каждой из тематик в обученных моделях (посчитать когерентность и для LLDA).
8. Описать недостатки, видные в полученных тематиках. Используя опыт с практических занятий и рекомендации на лекциях, настроить гиперпараметры LDA так, что тематики, на ваш взгляд, "на глазок" стали лучше.
10. Замерить когерентности теперь и у настроенной ВАМИ модели.
11. Сделать выводы и поделиться впечатлениями. Лучше в виде протокола в гуглодоке, чтобы можно было быстро вставлять скриншоты, но можно и plain text в комментарии на emkn.

Если вам удобнее работать в jupyter notebook -- можете присылать и в таком виде, нет проблем.
